How this library works

01

Links only

The repository stores one books.json. Nothing copyrighted is hosted; “Read free” always points at a copy the author or publisher has made freely available.

02

Classics only

A book gets in when it has stayed in print, gone through editions, and is what practitioners actually recommend. New and popular are not disqualifiers, but they are not enough.

03

Rights respected

Free links are checked one by one: the file must sit on the author's or publisher's own domain, or carry an open licence. No mirrors, no "found" PDFs. Rights holder who wants a link removed? Open an issue — it comes down promptly.

04

Add one in a minute

Search for a missing book. The site checks Open Library, previews whether it clears the bar, and lets you submit it. A GitHub Action re-checks and adds it; borderline cases wait for a maintainer.
